# TioTio
TioTio is a web system developed to assist school transport drivers in managing and controlling information related to their activities.

The system aims to centralize information about drivers, vehicles, students, guardians, schools, routes, contracts, expenses, payments, and notifications. By doing so, it seeks to facilitate the organization of information used in the driver's daily routine, as well as enable better tracking of costs, documents, and other responsibilities related to school transportation.
